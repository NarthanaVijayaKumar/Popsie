###### &#x20;   Input Employee ID, Name, Department, Basic Salary.



###### &#x20;   Store details in database/file.



##### 4.If View Employee selected:



###### &#x20;   Retrieve all employee records. 

###### &#x20;   Display details in tabular format.



##### 5.If Update Employee selected:



###### &#x20;   Input Employee ID.

###### &#x20;   Search for record.

###### &#x20;   Save updated record.



##### 6.If Delete Employee selected:



###### &#x20;   Input Employee ID.

###### &#x20;   Search for record.

###### &#x20;   Remove from database/file.



##### 7.If Calculate Payroll selected:



###### &#x20;   Input allowances and deductions.

###### &#x20;   Retrieve employee details and salary breakdown.

###### &#x20;   Display payslip in console or export to text file.



##### 8.If Exit selected:



###### &#x20;   Terminate program safely
